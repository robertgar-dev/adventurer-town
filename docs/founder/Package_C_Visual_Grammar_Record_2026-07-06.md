FOUNDER DECISION — Outcome Overlay Visual Grammar, Color Ladder & Accolade
Mounting Language (Package C)
Date: 2026-07-06
Status: RATIFIED — Robert, 2026-07-06 (delivered in-session; file verbatim)

§1 — Grade ladder rule ("one readable thing")
Each grade adds exactly ONE readable element over the grade below. Grades
are communicated by silhouette, material class, color saturation, and a
single focal element — never by overall detail or rendering polish. All
stamps must read at the ~116px Brindle floor.

§2 — Fittings, not garments
Stamps depict ADDITIVE FITTINGS an adventurer carries away from a service
(straps, caps, pads, plates) — never garments that replace the character's
own costume. Stamps are visual representations of engagement with the town
economy: prosperity and harder adventuring made legible on the body.

§3 — Color ladder (the wealth signal)
  HUMBLE: undyed naturals — hemp, bone cloth, raw tan leather. No dye,
  no metal warmth. Simple with dignity; never ragged or shabby.
  ESTABLISHED: first dye — deep russet leather, honest iron. The empty
  brass mounting point appears (blank plate/patch/rivet).
  GRAND: service-signature dye at full saturation plus polished brass;
  the mount is occupied by the canonical emblem. Wealth radiates through
  color and material warmth only — NO glow, NO magic effects.

§4 — Service signature colors
Each service owns one signature hue, worn only at Grand grade.
BLACKSMITH = deep forge-ember red (pulled toward oxblood in finish).
Remaining services (Inn, Tavern, Healer, Market) claim theirs in their
own future stamp records.

§5 — Canonical emblem & accolade mounting language
The Blacksmith emblem is a ROUND POLISHED BRASS ROUNDEL, hammer above
anvil, pictorial only, identical across all Grand stamps (enforced in
manual finish). The mounting point (one per slot: belt plate, chest
plate, shoulder rivet) is the permanent visual home for future accolades
— marks of recognition earned through play, never purchased. This record
bakes in LANGUAGE ONLY; any accolade mechanic requires its own record.

§6 — Slot concepts (Blacksmith, 9 stamps)
  BELT: rope tie + pouch → leather belt/knife/pouch + blank plate →
        ember-dyed belt, roundel plate.
  TORSO: quilted cloth chest pad → russet chest guard + blank plate →
        ember chest guard, roundel plate. (Wrap/bandolier concept
        REJECTED — reads only on a body; chest-piece is the anchor.)
  SHOULDERS: cloth pad + cord → riveted russet cap → ember cap, brass
        edge-line + roundel rivet.

§7 — Production status
V3 draft set (2026-07-06, nine 2K images, job set on file) is ACCEPTED
as the pilot draft basis. Known finish notes: unify roundel embossing
to the single best instance; pull grand-belt red ~10% toward oxblood.
V1 and V2 sets are archived concept iterations, not production inputs.
Weapon stamps (3) and all non-Blacksmith stamps (39) remain unauthorized.
